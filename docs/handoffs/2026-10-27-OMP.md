## Agreed scope

Finish the smallest complete native solution, with regression tests and review:

1. Reusable theme variants and explicit slots for teaching layouts, including
   task/citation/code/result frames and variant role styles. Preserve native
   exceptions and original-source authority; do not infer roles from IDs.
2. `.bento-card` for code backgrounds. Fix echoed-code + figure/table composition.
   Support bounded source chunk layout options and complete ordered outputs.
3. Static 2D plots prefer SVG; explicit source/project/chunk devices remain
   authoritative. 3D needs a faithful PNG fallback. Never shrink fonts or crop
   figures merely to hide overflow.
4. Long code/text/table outputs: explicit scroll inside the native slide region,
   full data retained, complete static/PDF continuations. No generated QMD edits.
5. Interactive Plotly scatter3d points/lines (plus existing supported 2D) inside
   the actual slide rectangle in Studio and standalone offline HTML. Explicit
   edit/interact modes and Escape; static fallback for printing/WebGL failure.
   Support bounded local R-htmlwidget HTML imports by extracting inert data only,
   without executing arbitrary scripts or faking an R execution receipt.
   Temporary exploration must not silently change source; explicit camera saving
   was discussed as a visual operation and still needs implementation/verification.
6. Native charts remain the existing bounded bar/line adapter. Preserve palette,
   font and geometry while recomputing data. No arbitrary ggplot conversion or
   reverse propagation of chart edits into R. Keep explicit detach behavior.

No environment manager, new dependency, Bento fork, general layout DSL, arbitrary
widget support or cross-platform release claim is authorized by this scope.
