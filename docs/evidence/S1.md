# S1 — original-QMD mapping and bounded content edits

Implementation evidence recorded 2026-10-11, Linux, Deno 2.9.6, Quarto 1.10.19.
This implements a conservative source scanner and content-patch primitive; it is
not a universal Markdown parser or a complete synchronization transaction.

## Verified behavior

- `scanSource(text)` maps original UTF-8 bytes, with end-exclusive spans and
  SHA-256 snapshots. It recognizes YAML front matter, ATX headings, paragraphs,
  fenced divs, displayed code, executable chunks, display math, and HTML
  comments.
- Explicit heading/div IDs, `<!-- qb:identity -->` block markers, and chunk
  labels are reused. Named chunk content remains computed and cannot be patched.
- Plain blocks get snapshot-local IDs. Children of a div get identifiers such as
  `finding/paragraph:1`; these are deliberately `stable: false` because sibling
  insertion can change their ordinal. Lifetime identity needs an explicit
  marker.
- `previewPatches(document, [{blockId, replacement, expected?}])` returns exact
  fragments and source/result hashes. `applyPatches(currentText, preview)`
  returns the approved replacement string only if the snapshot, fragments,
  spans, parsed structure, provenance, and preview result still agree. Neither
  function writes.
- Patches replace only the content span. Heading attributes, delimiters,
  comments, unrelated content and CRLF line endings survive. Multiple disjoint
  edits use original-byte offsets. Repeated/overlapping requests are refused.
- `resolveSourceMapping(document, evidence)` checks the execution source hash
  and an explicit source ID or unique exact literal. Computed, ambiguous,
  transformed, unsupported and stale mappings are refused. The execution adapter
  must pass computed provenance for cell descendants; literal coincidence is not
  provenance.
- The original S1 proof used top-level level-2 headings. The current default
  source mapping recognizes top-level H1 and H2, matching the native projector;
  see [the current slide-boundary contract](../AUTHORING.md#slide-boundaries-and-stable-identities).
  The preamble remains separately retained. `scanSource(text, {slideLevel})`
  still selects exactly the explicitly requested level. These are source
  boundaries, not approval to reorder execution dependencies.

## Reproduction

Offline source tests (no package download):

```sh
deno test --allow-read --allow-write tests/source_test.ts
deno lint src/source tests/source_test.ts tests/source_execution_test.ts
```

Real Quarto + R/knitr execution, using already-installed compatible
dependencies:

```sh
deno test --allow-read --allow-write --allow-run tests/source_execution_test.ts
```

The execution test creates a disposable QMD with heading `results`, div
`finding`, an authored paragraph, R inline output, and R plot chunk
`fig-values`. A final Pandoc Lua filter captures post-execution JSON. It checks
retained IDs, changes only the original authored paragraph, executes again and
checks the changed literal, then verifies reverse edits to the inline
computation and plot producer are rejected. Temporary source, HTML, assets and
AST are removed afterward. Without subprocess permission this integration test
is explicitly **ignored**, not counted as executed. The fixture does not infer
original byte offsets from post-execution Pandoc JSON.

Results: 11 source tests plus 1 real execution integration test pass; lint
passes. The dependency-free SHA-256 implementation is checked against WebCrypto
for empty, short, multiblock, and Unicode strings.

## Deliberate limits and integration obligations

- No automatic mapping through includes, cross-file content, arbitrary reader
  transforms, tables/lists/raw HTML, or rich inline rendering. Unsupported
  blocks stay readonly. Rendered Markdown-normalized text cannot be
  reverse-written by assuming its positions match original QMD.
- Fenced-div groups are not whole-block patch targets; map a specific authored
  child. Source-owned visual attributes need a separate field-edit operation.
- Structural creation/deletion/reordering is a distinct reviewed operation. A
  content replacement cannot smuggle a new slide, executable chunk, or boundary.
  Slide spans alone do not prove executable-cell independence or safe
  reordering.
- Filesystem locking, approval, atomic writes, backups, recovery journals, and
  advancing the confirmed baseline belong to the transaction/persistence layer.
  Callers must not treat this in-memory primitive as durable sync by itself.
- The scanner's structural checks are intentionally conservative. It does not
  promise arbitrary Pandoc AST ↔ Markdown round-trip or multi-QMD editing.

Review correction: explicit attribute parsing now removes enclosing braces
before tokenizing IDs. Regression coverage verifies sole/final IDs in
`::: {#card}`, `::: {.bento-card #card}`, and displayed code attribute lists.
Quoted attribute values remain excluded from identity detection.

## H1/H2 boundary alignment regression

The authored-scope guard exposed a mismatch: native projection already opened H1
slides, while the original mapper assigned slide spans only at H2. The current
default mapper now uses the same top-level H1/H2 boundaries. It retains the exact
explicit `slideLevel` scanner option; it does not infer a new YAML rendering option.

`tests/slide_boundaries_test.ts` checks mixed H1/H2/H3, nested component headings,
CRLF/Unicode byte spans, original preamble, checked reorder/delete, H1 optional
annotations, metadata-only deck title, reviewed weak identities, hidden slides,
one computation per render, and exact reconstruction without HTML. The paired
ordinary Quarto path tests also pass with an H1 and a QMD basename containing
spaces, both quote types and Unicode. Four boundary/path tests passed (22s); the
boundary/annotation run passed 17 tests (12s), and source/structure/slide-action/
sync/weak-math/KPI regressions passed 43 tests (2m4s). These focused runs overlap
and are separate from the full-suite receipt.
